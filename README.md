# 🚀 SapsMC

> **A sleek, modern Minecraft launcher built to make managing Minecraft feel WAY less annoying.**

### ✨ UI / Theme

SapsMC has a **Prism Launcher–inspired theme** with its own look and personality.

Think:

* 🖤 Dark, clean interface
* 📦 Instance-based Minecraft management
* 🎮 Big, easy-to-see instance cards
* ⚡ Quick launch controls
* 🛠️ Instance editing
* 📁 Easy access to instance folders
* 👤 Account management
* 🌌 Clean modern launcher vibes

> **SapsMC is NOT Prism Launcher.**
> The interface is inspired by the style and organization of Prism Launcher while remaining its own launcher.

### 🧩 Mods & Packs

SapsMC is built around managing content directly inside your Minecraft instances.

**MODS**

**PACKS**

* 📦 Resource Packs
* 🌈 Shader Packs
* 📂 Other

🚫 **No Modpacks section.**

### 🔥 The Goal

Make SapsMC feel like:

**Minecraft launcher + instance manager + mod manager + clean UI**

without making everything look like a 2009 Java application.
